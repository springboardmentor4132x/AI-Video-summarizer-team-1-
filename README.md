# ClipMind AI - Video Summarization Platform

An AI-powered video summarization platform that automatically analyzes videos, extracts transcripts, generates concise summaries, and identifies important moments.

## 🏗️ Repository Structure
This is a monorepo containing both the frontend and backend applications.
- `/backend`: FastAPI Python application
- `/frontend`: Next.js React application
- `/docs`: System architecture, API references, and wireframes

## 🚀 Getting Started
Please refer to `docs/setup.md` for detailed instructions on setting up your local environment, database connections, and environment variables.

## 🌿 Git Workflow (Strict)
- **Never push directly to `main`.**
- Create a feature branch: `git checkout -b feature/your-feature-name`
- Submit a Pull Request for review before merging.
