# ClipMind AI Frontend

This Vite React application provides the Module 1 user experience: registration, JWT login, protected role dashboards, video upload, role-scoped video libraries, upload history, and processing status.

## Run

```powershell
npm install
npm run dev
```

Set `VITE_API_URL` when the FastAPI backend is not running at `http://127.0.0.1:8000`.

## Build

```powershell
npm run build
```

AI summaries, transcripts, key-moment detection, and full administrator management screens are not implemented in Module 1.
